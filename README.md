# Alcove-Digital-Art-Gallery
#  Alcove – Digital Art Gallery (Task 6)**

## **1. Introduction**

Alcove – Digital Art Gallery is a web-based application designed to display digital artwork in an elegant and organized gallery. It provides users with an opportunity to explore different artworks, view detailed information about each piece, and submit their own artwork for review.

The main purpose of this project is to create a modern digital platform where emerging artists can showcase their creative work.

## **2. Objectives**

The main objectives of this project are:

- To create an online digital art gallery.
- To display artwork in an attractive layout.
- To provide detailed information about each artwork.
- To allow users to navigate between different artworks.
- To provide an artwork submission form.
- To create a responsive and user-friendly interface.

## **3. Technologies Used**

| Technology       | Purpose                           |
| ---------------- | --------------------------------- |
| HTML5            | Structure of the website          |
| CSS3             | Styling and responsive design     |
| JavaScript       | Application functionality         |
| SVG              | Creating digital artwork graphics |
| DOM Manipulation | Dynamically displaying content    |

## **4. Main Features and Modules**

### **4.1 Art Gallery**

The gallery module displays a collection of eight digital artworks created using SVG shapes.

Features:

- Displays multiple artworks.
- Shows artwork titles and artists' names.
- Displays the year of creation.
- Uses a responsive grid layout.
- Provides hover effects to reveal artwork information.
- Allows users to select artwork for detailed viewing.

### **4.2 Artwork Details**

This module provides complete information about individual artworks.

Features:

- Displays the selected artwork.
- Shows artwork title.
- Displays artist name and creation year.
- Provides artwork descriptions.
- Shows artistic medium.
- Displays artwork dimensions.
- Provides Previous and Next navigation.
- Includes a Back to Gallery option.

### **4.3 Artwork Submission Form**

This module allows artists to submit their artwork for review.

Features:

- Artwork title field.
- Artist name field.
- Email address field.
- Medium selection.
- Artwork size field.
- Artwork description field.
- Image upload option.
- JPG and PNG file support.
- Maximum file size of 10 MB.
- Form validation.
- Submission confirmation message.

## **5. Working of the Application**

The application works through the following steps:

1. The user opens the Alcove website.
2. The Gallery section displays eight digital artworks.
3. The user selects an artwork.
4. The application displays its detailed information.
5. The user can navigate to previous or next artworks.
6. The user can visit the Submit Artwork section.
7. The artist enters the required information.
8. The artist uploads an artwork image.
9. The application validates the entered information.
10. A confirmation message appears after successful validation.

## **6. User Interface and Design**

The application uses a modern and professional design.

Important design elements include:

- Responsive artwork grid.

## **8. Limitations**

The current application has the following limitations:

- No user registration or login system.
- No database integration.
- Artwork submissions are not permanently stored.
- Uploaded images are not sent to a server.
- No artist dashboard.
- No payment or artwork purchasing system.
- Gallery artworks are predefined.

## **10. Conclusion**

Alcove – Digital Art Gallery is a modern web-based application that provides an organized platform for displaying and exploring digital artwork. It allows users to view artwork details and provides artists with an artwork submission interface.

This project demonstrates the practical use of HTML, CSS, JavaScript, and SVG graphics in developing an interactive and responsive website. It provides a foundation for building a complete online art gallery in the future.
